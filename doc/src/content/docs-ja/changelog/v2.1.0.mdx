このリリースでは、残っていた複数行クラス抽出の抜けを解消し、オプトインの CSS z-index ルールを強化するとともに、現在の zudo-doc リリースで不要になったドキュメント側の回避策を廃止しました。

## クラス抽出

- 設定対象の JSX/Astro クラス属性は、物理行をまたぐ `{...}` をバランス走査するようになりました。配列と join の式、ネストした呼び出し、テンプレート補間内の条件付き文字列を、黙って見落とすことなく実際のソース行で抽出します（`eda079b`）。
- 属性のテンプレートリテラルは静的なクラス部分を出力し、`${...}` 分岐内の文字列リテラルも走査しますが、補間式そのものをクラスとして報告しません。ネストした設定対象関数は重複排除され、コメントと ignore メタデータの挙動も維持されます（`eda079b`）。
- 不正または閉じていない属性式は、無関係なソースまで消費せず、既存の継続 50 行の安全境界を維持します（`eda079b`）。

## CSS z-index ルール

- `css.zIndex` は `calc(70 + 1)` のようなトークンを含まない計算を拒否するようになりました。直接の `var(...)`、`var(...)` を含む `calc(...)` 式、標準 CSS キーワードは引き続き許可されます（`6abf8e6`）。
- オブジェクト形式で生の整数を明示的に例外指定できます: `"zIndex": { "allowed": [0] }`。既存の真偽値形式と、公開済みの `CompiledCssConfig.zIndex: boolean` 契約は後方互換のままです（`6abf8e6`）。
- CLI、設定検証、ブラウザー Playground のパリティ、README、英語/日本語リファレンスが同じ挙動を説明し、テストするようになりました（`6abf8e6`、`d71924c`）。

## ドキュメントサイト

- 更新された zudo-doc 統合では、設定済みのネストしたエントリードキュメントを使用し、アーカイブの CategoryNav リンクをそのバージョン内に保ち、Latest 専用の Claude ナビゲーションを正規 URL で表示し、利用できないアーカイブのスイッチャー遷移先を無効化します（`3b44451`）。
- 不要になったエントリーページと Claude のリダイレクトを削除しました。レガシーな `/v/:version/docs/claude*` パスは、現在のコンテンツをアーカイブラベルの下で配信せず、意図的に 404 を返します（`3b44451`）。
- 厳格なリンクチェックは、`aria-disabled=true` が明示されたアンカーのみを除外します。アクティブなリンクとリダイレクト先は、許可リストの例外ゼロで引き続き完全に検証されます（`3b44451`）。
- v2.0 ドキュメントのスナップショットは引き続き閲覧可能で、v2.1.0 が最新版になったため unmaintained と表示されます。

## メンテナンス

- zfb/zudo-doc ツールチェーンを更新し、テンプレートドリフト方針を同期しました（`b6d0c5e`、`aa01f5e`、`7356b7f`）。
- CI のキャッシュアクションを更新し、リリース時のアーカイブドキュメント用バナー切り替えを自動化しました（`609f111`、`bb5bed4`）。
