このリリースでは、リンターの動作と公開 API は変わりません。ドキュメントサイトのフレームワークと依存関係を更新しました。

## ドキュメントサイト

- ドキュメントサイトは zudo-doc 10.0.3、zfb 6.0.1 エンジン系列、zdtp 0.9.5 で動作するようになりました。katex は 0.19 に上がり、Preact、Tailwind、`@types/react` は依存関係から外れました（`d213d7c`、`b35c6a5`）。
- Playground とドキュメントのルートを Preact から zudo-react ランタイムに移植しました。スタイルは Tailwind ではなく zudo-wind ユーティリティコンパイラで生成します（`e7cb90e`）。
- ドキュメント用の CI ワークフローは、zudo-doc が必要とする Node 24 で動作します。リンターパッケージは引き続き Node 18 以降をサポートし、CI では Node 20・22・24 でテストしています（`177d81b`）。
- テンプレートのドリフト許可リストを create-zudo-doc 10.0.3 基準で作り直しました（`b5783c3`）。

## 修正

- Playground で、保持された結果行が、設定の変更に合わせて理由のテキストを更新するようになりました（`4261541`）。
- 設定ページと API ページのページ内リンクが、新しい見出し ID を再び指すようになりました。見出し ID にインラインコードのテキストが含まれるようになったためです（`7d59ce2`）。
