このリリースでは、Tailwind の任意値（arbitrary value）クラスを対象とするオプトインのチェックを追加しました。組み込みの z-index プリセットはこのチェックを有効にしているため、プリセットを使っているプロジェクトでは `z-[70]` のようなブラケット記法のクラスが新たに検出される場合があります。

## リンター

- 構造化された `prohibited` エントリで `arbitraryValues: "check"` を指定できるようになりました。指定すると、`z-[70]`、`-z-[1]`、`hover:z-[60]` のようなブラケット記法のクラスをスキップせずに評価します。`var()` や `calc(var())` でトークンを参照する値は通過し、トークンを含まない `calc()` は検出されます（`aa54545`）。
- 組み込みの z-index プリセットはこのチェックを有効にしています。生のブラケット記法の z-index クラスが、既存の `css.zIndex` チェックと同じ基準で報告されるようになりました（`aa54545`）。
- ドキュメントのプレイグラウンドも新しいチェックに対応しました（`aa54545`）。

## ドキュメント

- 設定ガイドと API リファレンスで `arbitraryValues` と z-index のブラケット記法チェックを説明しました（`eeee850`）。
- ドキュメントサイトを zudo-doc 11.0.0 と zdtp 0.9.7 に更新しました（`8092473`、`e83ff98`）。
