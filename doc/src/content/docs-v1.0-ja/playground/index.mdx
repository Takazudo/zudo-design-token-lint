ブラウザ上でリンターを直接試せます。左側にコードを貼り付け、設定を調整すると、右側に違反が表示されます。

<Note>

インタラクティブ Playground は 4.x ドキュメントサイト再スキャフォールド（issue #144）の間、一時的に無効化されています。後続のウェーブで新しい `chromeBindingsModule` 拡張ポイントを通じて再接続される予定です。

</Note>
