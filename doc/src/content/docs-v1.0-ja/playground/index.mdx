ブラウザ上でリンターを直接試せます。左側にコードを貼り付け、設定を調整すると、右側に違反が表示されます。

<Note>

このアーカイブ済み（1.0.0）バージョンのドキュメントでは、インタラクティブ Playground は利用できません — 旧 Astro island のワイヤリングは現在のドキュメントサイトのビルドでは動作しません。[最新版の Playground](/docs/playground/) をご利用ください。

</Note>
