ブラウザ上でリンターを直接試せます。左側にコードを貼り付け、設定を調整すると、右側に違反が表示されます。

<Note>

この固定（2.0.0）バージョンのドキュメントでは、インタラクティブ Playground は利用できません。Playground はドキュメントサイトのライブ lint ミラーを使用しており、これは常に最新リリースに追従します — そのためアーカイブページ上では 2.0.0 より新しいリンターの結果を表示してしまいます。[最新版の Playground](/docs/playground/) をご利用ください。

</Note>
