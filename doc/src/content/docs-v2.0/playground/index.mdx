Try the linter directly in your browser. Paste your code on the left, adjust the configuration, and see violations on the right.

<Note>

The interactive Playground is not available in this pinned (2.0.0) version of the docs. It runs the doc site's live lint mirror, which always tracks the current release — so on an archived page it would report results for a linter newer than 2.0.0. Use the [latest Playground](/docs/playground/) instead.

</Note>
